# Globetrotters 🌏 – Tourism Website

**Globetrotters** — Explore India is a fully responsive travel website designed to help users 🌏 discover, explore, and book ✈️ trips to some of India’s most breathtaking destinations.
The project focuses on UI/UX design principles, accessibility, and modern front-end development practices.
I built it as my 2nd-year college project.

## ✨ Key Features

🖥 Responsive Navigation Bar — Adaptive menu with a hamburger toggle for mobile devices 📱.

🗺 Interactive Booking Form — Live destination filtering 🔍 and date picker 📅 for trip planning.

🎨 Clean UI with user-friendly layout.

🏞 Visually Appealing Destination Cards — Hover animations 🎨 and lazy-loaded images ⚡ for smooth performance.

🏕 Clickable Service Categories — Direct navigation to relevant sections for quick access.

♿ Accessibility-Friendly Design — Semantic HTML & ARIA labels for inclusive browsing.

🚀 Optimised Performance — Mobile-first approach, image optimisation, and minimal load times.

---

## 🛠 Tech Stack

**Languages & Markup**

  - HTML5 — Semantic, accessible structure.

  - CSS3 — Responsive layout with Grid & Flexbox, custom variables, and animations.

  - JavaScript (ES6) — Client-side interactivity (menu toggle, form handling, filtering).

**Tools & Libraries**

  - Google Fonts — Poppins & Open Sans for typography.

  - Font Awesome — Icons for navigation and UI elements.

**Performance & UX Enhancements**

  - Lazy loading for images.

  - Mobile-first responsive design.

  - ARIA labels and semantic HTML for accessibility.
